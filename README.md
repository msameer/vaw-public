# Villagers at Work

A Fabric mod that puts villagers to work at their stations.

- **Wiki:** https://msameer.github.io/vaw-public/
- **Download:** [CurseForge](https://www.curseforge.com/minecraft/mc-mods/villagers-at-work) · [Modrinth](https://modrinth.com/mod/villagers-at-work)
- **Report a problem or suggest an idea:** [open an issue](https://github.com/msameer/vaw-public/issues/new/choose)

This repository holds the published wiki and the mod's public issues. The wiki here is replaced with
each release, so it always describes the version you can download.
