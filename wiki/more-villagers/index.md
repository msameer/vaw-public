**A separate mod, and it needs Villagers at Work.** It adds professions of its own, each with a job site you build and a place in the village's supply chain. Install its jar beside the mod (see [Installation](/installation/)). Everything in this section happens only with it installed.

**It goes on the server and on every player's game.** A new profession has to be known to every game that shows it, so unlike the mod itself, players cannot join without it.

**Each profession needs only the mods its own work comes from.** Without one, More Villagers at Work still runs, without that profession.

| Profession | Job site | Needs |
| :---- | :---- | :---- |
| [Chef](/more-villagers/chef/) | A Farmer's Delight cabinet with a shelf touching it | Farmer's Delight |
| [Beekeeper](/more-villagers/beekeeper/) | A beehive with a shelf touching it | Nothing more |
| [Lumberjack](/more-villagers/lumberjack/) | A chopping block, its own block | Nothing more |

More professions will follow.
