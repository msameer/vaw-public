# More Villagers at Work

**A separate mod, and it needs Villagers at Work.** It adds professions of its own, each with a job site you build and a place in the village's supply chain. Install its jar beside the mod (see [Installation]({{ site.baseurl }}{% link installation.md %})). Everything in this section happens only with it installed.

**It goes on the server and on every player's game.** A new profession has to be known to every game that shows it, so unlike the mod itself, players cannot join without it.

**Each profession needs only the mods its own work comes from.** Without one, More Villagers at Work still runs, without that profession.

| Profession | Job site | Needs |
| :---- | :---- | :---- |
| [Chef]({{ site.baseurl }}{% link more-villagers/chef.md %}) | A Farmer's Delight cabinet with a shelf touching it | Farmer's Delight |
| [Beekeeper]({{ site.baseurl }}{% link more-villagers/beekeeper.md %}) | A beehive with a shelf touching it | Nothing more |

More professions will follow.
